记账喵 1.0.0 - 本地优先的生活费记账伙伴

此安装程序只安装到当前 Windows 用户，不需要管理员权限。
支持 Windows 10/11 64 位。运行需要系统 Microsoft Edge WebView2 运行时和 .NET Framework 4.6.2 或更高版本。
安装包已包含 Python 运行环境，不需要用户另装 Python、Node 或设计软件。

记账功能不依赖互联网。默认关闭开机自启动，设置页中可主动开启。
桌面账本保存到当前用户 LocalAppData\MeowLedger\ledger.sqlite3。
网页、手机和桌面账本分别保存，不自动同步。原网页账本请导出 JSON 后导入桌面版。
卸载会移除程序、快捷方式和本应用自启动项，但保留账本和自动备份。
请定期从设置页导出 JSON 备份。

手机使用的是另行提供的响应式网页/PWA，需要 HTTPS 部署地址，不能运行此 EXE。
此版本尚未公开部署手机网页，也未对安装程序进行代码签名。
