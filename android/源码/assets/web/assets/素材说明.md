# taffy 上半身素材

- 最终素材：`companion.png`，1536 × 1024，RGBA 真透明，三列两行；每格 512 × 512。
- 来源：用户提供的三视图/表情图 `D:/素材库/ChatGPT 图像 2026年10月12日 20_20_00.png`。
- 制作方式：内置 ImageGen 参照原图生成透明上半身精灵图；不是整张设定图缩小，也不是原图像素级剪裁。已视觉检查服装、发型、配色和现有神态；仍可进一步调整素材一致性。
- 无 Photoshop/AE/PR 工程，本轮未使用这些制作软件。动画来自可编辑的 CSS，不依赖这些软件运行。
- 担心/低落共用原图汗滴神态，通过温和文案和轻微动作区分；不额外创造新的面部表情。

| 行/列 | 对应神态 | CSS 位置 |

运行时采用 CSS 精灵帧定位；所有展示格保持正方形，不拉伸人物比例。外加轻微呼吸、歪头、叹气和泪滴，不使用视频。尊重减少动画，后台或不可见时暂停。
