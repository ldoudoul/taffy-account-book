# 记账喵 Android 1.0.0

安装包：安装包/记账喵-1.0.0-Android.apk。
适用Android 8.0及以上；使用系统Android System WebView，请保持其更新。APK不含原生CPU库，适用于常见ARM、ARM64、x86及x86_64手机/模拟器。首版为自行签名的本地安装包，未上架应用商店。

## 安装和使用

1. 把APK通过USB、微信文件或其他文件传输方式保存到安卓手机。
2. 在手机文件管理器中点开APK，按系统提示允许本次来源安装，再安装「记账喵」。
3. 从手机桌面打开应用，设置当月生活费，即可记账。无需访问网页地址，首次打开即可离线运行。
4. 如果提示解析或安装失败，核对系统版本、文件是否完整及可用空间；具体系统阻止提示需按手机实际说明处理。

不适用于iPhone，也不需要安装Windows EXE、Python或服务器。

## 数据与备份

- 账本保存为应用私有目录的ledger.json；通过Android AtomicFile事务式写入，保存失败不更新界面状态。
- 关闭应用后保留；卸载应用或清除应用数据会删除账本。卸载前在「设置 → 完整JSON备份」保存到手机文档/下载位置。
- JSON与CSV导出使用系统保存文件界面，可自行选择目录；导入使用系统打开文件界面。导入先校验，合并按ID去重，覆盖前要求完成备份并确认。
- 安卓、网页和Windows账本独立，不自动同步。原电脑版或网页版数据需导出JSON，再在安卓设置页导入。
- 没有请求网络、联系人、定位、相机或全部文件访问权限；仅访问用户通过系统文件选择器选中的备份。

## 实现与源码

Windows的Python后端不打进Android。手机沿用已验证的等价JavaScript整数分业务引擎，Java只负责系统WebView、私有文件持久化、文件选择、返回键和后台暂停。
全部HTML/CSS/JS与人物图片内置APK，通过固定HTTPS来源的本地资源拦截加载。没有网络服务器或首次在线缓存要求，未使用Electron或完整Chromium。
人物和五档20%预算消耗区间沿用已确认版本，主角色只显示上半身。Windows项目保持不变。

源码：源码/AndroidManifest.xml、源码/java/cn/meowledger/app/MainActivity.java、源码/assets/web。
构建：先运行准备工具.py，再运行构建APK.py。需要Python3，构建工具放项目目录内，无需配置系统PATH。构建脚本使用官方JDK和SDK的aapt2、javac、D8、zipalign及apksigner。
再次构建须沿用本机「签名」目录，才能作为同一应用升级。源码交付ZIP不包含签名密钥、密码和大型构建工具。
