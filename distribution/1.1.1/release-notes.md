# 永雏塔菲记账本 1.1.1

应用名称：记账喵。Windows 与 Android 安装包现已提供。

- 白色与粉色卡片界面升级、四种人物表情和七种道具互动。
- 音效默认关闭，可在设置开启；使用轻量合成音效。
- 两端采用用户提供的新图标，保留原图构图。
- Windows 10/11 x64，约 18.87 MiB，需要系统 WebView2 与 .NET Framework 4.6.2+，内置 Python。
- Android 8.0+，约 5.02 MiB，需要可用的系统 WebView；沿用原签名，可覆盖升级。
- 手机和电脑分别本地保存账本，数据不自动同步；升级前可导出 JSON 备份。

16 项 Python 测试、Python/JS 一致性、浏览器互动及安装包图标核验通过。Android v2/v3 签名、对齐通过；尚未安卓真机安装及音效听感验收。Windows 新版尚未在干净电脑安装验收，安装包未做商业代码签名。

请下载对应平台的 EXE/APK。SHA256SUMS.txt 提供校验值；该版本源码在 v1.1.1 标签及 interactivity 分支。
