# 永雏塔菲记账本 · 记账喵 1.0.0

Windows 10/11 x64 安装包，16,806,826 字节（约16.0MiB）。

下载 Assets 中的 `taffy-account-book-1.0.0-windows-x64-setup.exe`，双击安装，从桌面快捷方式启动。安装无需管理员权限，默认关闭开机自启动。

使用 Python + SQLite 和系统 WebView2。安装包内含 Python；系统需 Microsoft Edge WebView2 和 .NET Framework 4.6.2 以上。三份PDF说明随安装包提供。

首次账本为空；网页、安卓与Windows账本独立，转移使用JSON备份。安装包未代码签名，本机安装、启动、卸载及持久化已验证；另一台干净电脑及Windows实际重启尚未验证。

`SHA256SUMS.txt` 提供原始文件校验值。此版本发布的是此前完成本机验证的同一安装包。
