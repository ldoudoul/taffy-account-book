# 记账喵 1.1.0 · 界面与互动升级

日期：2026-10-14。本次升级纳入 v1.1.1 Release，1.0.0 历史 Release 保留。

## 界面与人物
白色底、暖白侧栏、玫瑰粉强调色、细边框、浅阴影和等宽金额数字。卡片左下角原头像保持无框与 80% 不透明度。

人物采用参考图右侧四表情的透明上半身编辑素材，保留粉发、齿轮、小动物头饰、黑金蝴蝶结和青绿饰品。使用内置 imagegen 编辑、去背景，并非逐像素原图裁切。

五档预算计算不变：消耗 0–<20% 金钱眼，20–<40% 露齿笑，40–<60% 与 60–<80% 共用担忧，≥80% 哭泣；未设预算使用露齿笑并标注“等待新计划”。收入不改变预算，超支仍保留最后一档。

## 互动
七个道具：游标卡尺、算盘、钱包、小账本、猫爪、金币、计算器。点击显示用户提供的台词、短动画和临时表情，1.1 秒后恢复预算表情；连续点击取消旧反馈。打开小账本按钮进入记账表单，点击道具不修改财务数据。

音效默认关闭，设置中开启后由点击触发。使用轻量 Web Audio 合成效果，猫叫为拟声，不是真实录音。减少动画、隐藏角色和关闭提示继续有效，后台暂停声音。sounds 为可选布尔设置，旧账本补 false，JSON 备份保留此设置。

## 验证与限制
- 16 项 Python 测试与 Python/JS 一致性测试通过。
- 隔离 Chrome 1440/390 宽度：无横向溢出和 JS 异常；七道具、记账入口、设置持久化、隐藏角色、减少动画通过。
- 五档预算及超支的表情坐标、互动后恢复已验证。
- 打包后 WebView2 运行诊断通过，使用隔离测试账本。
- Android 构建、v2/v3 签名和 zipalign 通过，versionCode 为 2，沿用原签名；未做真实手机安装与音效听感验收。
- 新 EXE 已构建，未在干净电脑重新安装。旧版三份 PDF 为 1.0.0 资料，本说明记录升级增量。

## 使用
Windows 安装 1.1.0 EXE，Android 8+ 安装 1.1.0 APK，升级前建议导出 JSON。手机和电脑数据分别保存。

Web：在 desktop/源码/dist 中运行 `python -m http.server 8877`，访问 http://127.0.0.1:8877/ 。手机 PWA 正式访问需 HTTPS 部署。

## 素材编辑记录
内置 imagegen 编辑提示词：仅提取参考图右侧四个上半身表情，按金钱眼、哭泣、露齿笑、担忧组成透明 2×2 精灵图。保持发型、服饰、线条、比例和表情，移除边框、背景、文字及全身视图，不添加 3D 或额外细节。第二次编辑移除背景光晕，保留人物。

保存位置：desktop/源码/dist/assets/taffy-expressions.png；安卓对应 assets/web/assets 下。无 AE/PR 工程。
