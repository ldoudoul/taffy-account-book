# 记账喵 1.0.0验收记录

日期：2026-10-12。所有新增验证账本使用项目「验证」下隔离目录，原网页和用户账本未覆盖。

## 已验证

- Python unittest共15项通过：整数分、非法输入、五档边界、收入独立、跨月修改删除、组合筛选、合并去重、CSV公式保护；SQLite重开、回滚、revision冲突、覆盖备份与备份失败拒绝覆盖。
- Python/JavaScript等价规则测试通过。前端源文件语法检查通过；此前浏览器320/390像素布局无横向溢出。
- 源码及冻结EXE使用WebView2成功加载，Python/SQLite桥接ready=true。安装包内不含用户或测试账本。
- 实际桌面界面设置2000元预算，保存400元餐饮支出，显示剩余1600元、20%消耗与第二档角色。关闭后再次启动诊断，预算、账单及revision=2保持。
- 桌面JSON导出通过系统另存为对话框，备份金额为整数分，内容与SQLite一致。
- 桌面自启动界面开关实际开启HKCU Run项，关闭后该项不存在；测试后恢复为默认关闭。
- 同一数据目录重复启动退出第二进程并唤醒原窗口。
- 当前用户安装、安装后运行诊断及静默卸载返回0；程序移除，隔离SQLite账本保留。
- 三份PDF全部页面渲染检查，中文显示、页码、边距正常。

## 测量口径

精确文件字节数和安装包SHA256见交付测量.json。MiB=1048576字节。
安装后大小为程序目录全部文件长度之和，包含三份PDF与卸载器；不含系统已有WebView2、用户SQLite及浏览器缓存，也不等于文件系统分配空间。
运行依赖：Windows10/11 x64、WebView2运行时、.NET Framework4.6.2以上。安装程序包含Python，不包含完整Chromium。当前机器已有相关运行时。
