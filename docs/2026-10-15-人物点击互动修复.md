# 2026-10-15 人物点击互动与桌面图标修复

## 使用方式
先在小物桌选择状态，再点击粉色半身塔菲触发动作、对应道具和文案。Enter / 空格也可触发。动作结束后恢复预算对应表情。默认状态为小账本。

## 修复
- 道具按钮仅选择状态，不再立即播放；人物提供实际点击入口。
- 四张原有表情使用固定图层交叉淡入淡出（350ms），取消瞬间切换精灵图背景位置。
- 人物轻动作、随身道具以 transform / opacity 执行；再次点击从当前显示的姿势开始，取消上次动作与计时器。
- 页面不可见、人物滚出可见区、切换页面时清理动画；遵循系统及应用的减少动画设置。
- 七种道具采用轻量移动、旋转及表情反馈；素材仍为原图，不包含逐帧手臂骨骼动画。
- Windows 桌面及开始菜单快捷方式明确引用安装目录中的 taffy-desktop.ico；安装脚本也加入该图标资源及快捷方式设置。

## 已验证
- Chrome：七种状态依次选择、点击人物触发、结束恢复。
- 连续点击 20 次，活动动画数量为 2，没有累积队列；重触发前后姿势矩阵一致。
- 390px 手机布局无横向溢出；Enter 触发、减少动画模式通过。
- 本机 Windows WebView2 桌面版启动成功；选择钱包后点击人物出现对应互动文案。
- 桌面快捷方式目标及 IconLocation 回读正确，桌面截图中图标为用户提供的抱算盘塔菲。
