# 区块二：程序开发

已完成：Python业务核心、SQLite事务与版本检查、Windows WebView2桥接、账单CRUD/筛选、预算和备份。

安卓：Java系统WebView外壳，HTTPS本地资源拦截、私有AtomicFile保存、系统文件导入导出、返回键及后台暂停；等价JavaScript业务引擎保持整数分。全部资源内置APK。

网页：HTML/CSS/JS与PWA、本机浏览器存储和离线引擎，静态部署不要求Python服务器。

源码分为desktop/源码和android/源码；未包含用户账本或签名密钥。后续修改应同步核对Python和两个前端的业务规则。
