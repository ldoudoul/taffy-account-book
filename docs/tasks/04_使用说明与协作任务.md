# 区块四：使用说明与协作

根README覆盖结构、依赖、源码运行、构建、数据独立、人物规则和验证范围；desktop/文档提供三份PDF与可编辑Markdown，android/安卓安装说明.md提供手机安装和备份说明。

Windows安装包已发布到GitHub Releases v1.0.0，根README顶部提供直接下载链接与SHA256校验文件。distribution/windows保留已验证安装包作为自动发布输入；安卓安装包仍保留在原本地交付目录。

Windows卸载保留账本；安卓卸载/清除应用数据会删除账本，需先保存JSON。网页、安卓和桌面不自动同步；手动JSON迁移。

GitHub发布仅含源码、运行资源及文档，排除密钥、账本、缓存和大型SDK；仓库地址与可见性以实际创建结果为准。
