# 区块一：需求与设计

应用名记账喵，角色taffy；首页“今天也要好好记帐喵”，账单“一笔记账，心里有数”。白底粉色卡片，手机单列底部导航、桌面侧边导航。

每月预算独立；剩余预算=预算-支出。收入单独统计，不自动增加预算。人物按预算消耗每20%切换，顺序见根README；只展示上半身。五张原图人物在卡片左下角无框打底、80%不透明度。

已形成需求与设计PDF及Markdown，位于desktop/文档。首版本地优先，不自动跨端同步。

后续：根据真机及用户验收调整触摸、软键盘、安全区；云同步只作为另行明确的后续功能。
