# 1.2.0 人物短动画版

日期：2026-10-15。

## 动作与交互
六种状态：金币（双手抱金币、星星眼闪光）、猫爪（猫耳及开心表情、轻摆）、算盘（手持算盘、珠子亮起）、账本（捧本与轻翻页）、卡尺（双手持尺、游标光效）、计算器（按键姿势、屏幕与按键亮起）。钱包状态已删除。

先选择小物状态，再点人物。每次动作约2.2秒，350ms淡入淡出，结束恢复触发前的预算表情。动作是透明关键姿势配合轻量分层摆动与局部光效，不是视频播放；同一张原画跨图层淡入淡出。所有摆动以腰线为基准，只使用水平剪切，保持底边Y不变。连续点击取消旧动作并衔接当前姿势；关闭动画时保留状态、文案和复位。

## 本地验证
- 16项 Python 测试、Python/JavaScript一致性通过。
- 六种状态分别触发、播放、复位；每种采样8帧，人物底边偏移最大值均为0。
- 连续点击20次，活动动画为4个；前后姿势矩阵仅浮点精度误差；减少动画及390px手机布局通过。
- Windows旧版卸载、新安装器安装退出码为0；安装版WebView2诊断 ready=true、版本1.2.0；金币文案在安装版真实点击触发。
- Windows桌面及开始菜单快捷方式使用用户提供的抱算盘塔菲图标。
- APK签名及zipalign通过；versionCode=4，保留原签名支持覆盖升级。Android真机安装未测试。

## 动画来源与可编辑文件
人物动作透明图使用内置 imagegen 工具，以原表情图为参考生成。提示：保持粉色头发、呆毛、齿轮发夹、小动物头饰、白泡袖、黑金蝴蝶结与青绿胸针，制作3×2透明上半身动作图，包含抱金币、猫耳、算盘、账本、卡尺与计算器，身体底边一致，不加文字和边框。

本机交付目录 D:/素材库/记账喵-1.2.0-人物动画版/动画工程 包含 After Effects 2025 保存的六合成可编辑 AEP、生成 JSX、原透明素材及六张AE渲染预览。运行时使用PNG及JavaScript合成动画，不依赖AE。AEP为可编辑动效工程参考，运行时还包含可中断逻辑与局部光效。

## 安装与数据
Windows面向当前用户，不要求管理员；桌面启动。安装包包含Python，运行依赖Windows系统WebView2和.NET Framework。删除旧程序并重新安装保留现有本地账本；桌面与手机不自动同步。请在设置导出JSON备份。
