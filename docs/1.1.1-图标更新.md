# 记账喵 1.1.1 · 新图标版

Windows 与 Android 均使用本次用户提供的原图。仅进行等比例缩放和格式转换，保留透明背景、人物与算盘构图。

Windows：安装程序和应用程序均嵌入 16/24/32/48/64/128/256 像素 ICO，桌面及开始菜单快捷方式引用应用 EXE 图标。下载安装 1.1.1 后使用新版快捷方式。
Android：使用 192×192 PNG，包名与原签名保持一致，versionCode 从 2 提升到 3；可安装升级，不需要先卸载。不同启动器可能加圆形或圆角遮罩，属于系统行为。覆盖安装前建议导出 JSON 备份。
网页/PWA：同步更新 favicon、主屏幕 PNG 图标和缓存版本。

验证：EXE/安装包内七档图标资源与生成 ICO 一致；APK 的可见像素与新 PNG 一致。APK v2/v3 签名及 zipalign 通过。尚未进行 Android 真机桌面图标验收。
安装包校验值见 图标与安装包校验.json。源代码位置为 D:/素材库/记账喵-GitHub发布。
